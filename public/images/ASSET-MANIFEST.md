# Required Image Assets

Place the following files in this directory before building for production.
Until real assets are provided, the site will use styled placeholder backgrounds.

| Filename              | Description                          | Recommended Size   |
|-----------------------|--------------------------------------|--------------------|
| `crest.svg`           | School crest / logo (SVG preferred)  | Any (vector)       |
| `crest-64.png`        | Crest favicon / small icon           | 64x64 px           |
| `building-hero.jpg`   | Main school building photograph      | 1920x1080 px min   |
| `hero-slide-1.jpg`    | Background slideshow image 1         | 1920x1080 px       |
| `hero-slide-2.jpg`    | Background slideshow image 2         | 1920x1080 px       |
| `hero-slide-3.jpg`    | Background slideshow image 3         | 1920x1080 px       |
| `hero-slide-4.jpg`    | Background slideshow image 4         | 1920x1080 px       |
| `og-image.jpg`        | Social sharing image                 | 1200x630 px        |
| `primary-section.jpg` | Primary section photograph           | 800x600 px         |
| `junior-section.jpg`  | Junior secondary photograph          | 800x600 px         |
| `senior-section.jpg`  | Senior secondary photograph          | 800x600 px         |
| `leadership.jpg`      | School leadership photograph         | 800x600 px         |
| `student-life.jpg`    | Student activities photograph        | 800x600 px         |
| `gallery-1.jpg`       | Gallery preview image 1              | 600x400 px         |
| `gallery-2.jpg`       | Gallery preview image 2              | 600x400 px         |
| `gallery-3.jpg`       | Gallery preview image 3              | 600x400 px         |

All photographs should be high quality, well-lit, and representative of the actual school.
